# Mawood Characters

Personality summaries and avatar concepts for Mawood town NPCs, derived from their dialogue trees (`src/data/dialogues/mawoodTown/`, `src/assets/locales/en/dialogues/mawood*.json`).

- [Corwin](corwin.md) — town elder, bark-fused, guilt-driven
- [Brenna](brenna.md) — carver/armorer, blunt and proud
- [Elarion](elarion.md) — magic shopkeep, eccentric ex-court mage
- [Finn](finn.md) — trapper/scout, terse and guarded
- [Milo](milo.md) — orphan kid, reckless canopy scout
- [Sylvie](sylvie.md) — apothecary, warm and talkative

## Shared visual thread

All are Elderwood canopy-dwellers — palette should lean pale bark whites/greens/browns, with black-sap corruption as an optional dark accent (Corwin's bark glow, a stray drop on Brenna's workbench). Style reference: bold ink linework, flat cel shading, earthy muted palette, bust chest-up framing, soft drop shadow, rounded-corner canvas (see `src/assets/img/avatars/laHarpar/laHarparElara.png`, `laHarparMarvin.png`).

Lighting note from `docs/design/mawood-and-elderwood-zones.md`: the whole town sits in forest-canopy twilight, lit by bioluminescent moss/fungi rather than sun — favor cool pale-green ambient light over warm daylight, except Milo's high platform which breaks into open sky.

Note: all six current files in `src/assets/img/avatars/mawood/` are the same placeholder image — asset generation for Mawood is in progress (see [buildings](../mawood-buildings/README.md) for the matching building-background briefs).
