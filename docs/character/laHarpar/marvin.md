# Marvin — Exploration Guild Master

## Personality
Professional, direct, mission-focused — introduces himself by function first ("head of the Exploration Guild"). Structures the world for the player in concrete systems (contracts, Explorer Tokens, unlock gates) rather than gossip or lore. Encouraging without flattery ("Fine work out there!"). The one villager Elara and the Trader both single out as competent.
