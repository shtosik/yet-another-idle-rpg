## Shared visual thread

Coastal fishing village — palette leans sea-worn browns, faded blue-grey, sun-weathered skin tones, vs. Mawood's forest greens/pale bark. Style reference stays consistent across both towns: bold ink linework, flat cel shading, bust chest-up framing, soft drop shadow, rounded-corner canvas.
