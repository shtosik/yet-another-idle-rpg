# Enemy affixes

**Scope:** S-M · **Status:** Noted (owner not keen, 2026-10-24)

Small chance for a spawned enemy to roll an affix with a modifier and better loot: **Armored** (more HP), **Swift** (despawns if not killed in N seconds), **Regenerating** (heals over time), **Gilded** (extra gold). Variety without new art; the roll sits next to the shiny roll.

Owner isn't keen on it. Kept for reference.
