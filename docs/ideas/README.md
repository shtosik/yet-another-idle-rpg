# Ideas

Backlog of game-design ideas (2026-10-20). One idea per file. Not commitments.

Status is one word: Proposed, Accepted, In progress, Done, Noted or Open. Each file's `**Status:**` line starts with that word and holds the detail (what shipped, what is open); `npm run validate` fails when this table and the file disagree. Change the file's line first, then the table.

Owner decisions in force:
- Runes are **not** a spell cost (mana covers that). Recipes don't need runes.
